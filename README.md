# spindle

A from-scratch LLM inference engine in C++20 that runs GPT-2 and TinyLlama on a laptop CPU, with no ML libraries. See [docs/SPEC.md](docs/SPEC.md) for the goals and milestones.

## Build and check

Requires CMake 3.25+, a C++20 compiler and Python 3.14 (for the pinned clang-format and clang-tidy, and for generating reference outputs).

```sh
./tools/check.sh
```

This is the same command CI runs. It checks formatting, generates the reference outputs, builds and tests both the Release and the AddressSanitizer/UBSan builds, fails if any test is skipped, and runs clang-tidy.

## Benchmarks

```sh
./build/release/bench/spindle_bench
```

Results, with the machine and command for each, are in [docs/NOTES.md](docs/NOTES.md).

## Reference outputs

Tests compare against outputs from Hugging Face Transformers, generated by `tools/reference.py` from a pinned GPT-2 revision with pinned package versions (`requirements-reference.txt`). NumPy reference cases for single ops come from `tools/op_reference.py` with a fixed seed. `tools/tokenizer_reference.py` encodes 1,242 strings with the Hugging Face tokenizer: 42 written by hand and 1,200 generated with a fixed seed, all written for this project rather than taken from a benchmark. It also records how the tokenizer classifies every Unicode code point. None of these are committed; `tools/check.sh` regenerates them all into `build/reference/` on every run.

The first run installs PyTorch and Transformers into `.venv-reference/` (about 930 MB) and downloads the GPT-2 weights (548 MB) into the Hugging Face cache. Later runs take a few seconds. The dumps for the 5 prompts in `tests/reference/gpt2_prompts.json` are about 16 MB.

Python is used only here, never at runtime.

To build and run the CLI on its own:

```sh
cmake --preset release && cmake --build --preset release
./build/release/spindle --version
./build/release/spindle tokenize --model build/reference/gpt2/model "Hello, my name is"
./build/release/spindle detokenize --model build/reference/gpt2/model 15496 11 616 1438 318
```

`build/reference/gpt2/model` is a link to the GPT-2 files that `tools/check.sh` downloads. Any directory holding GPT-2's `vocab.json` and `merges.txt` works.

## Unicode tables

The tokenizer's letter and number tables in `src/unicode_data.inc` are generated from Python's Unicode database by `tools/gen_unicode_tables.py` (currently Unicode 16.0.0). A test compares them against the Hugging Face tokenizer on every code point.
